# JRS JOSHIM অনলাইন ফ্যাশন শপ

এটি একটি Node.js + SQLite ভিত্তিক অনলাইন দোকানের স্টার্টার প্রজেক্ট। ক্রেতারা পণ্য দেখতে, কার্টে যোগ করতে ও অর্ডার দিতে পারবেন। অ্যাডমিন প্যানেল থেকে পণ্য, ছবি, স্টক, অর্ডার এবং বিজ্ঞাপন নিয়ন্ত্রণ করা যাবে।

## চালানোর নিয়ম

1. কম্পিউটারে Node.js 18 বা তার পরের সংস্করণ ইনস্টল করুন।
2. এই ফোল্ডারে টার্মিনাল খুলে `npm install` চালান।
3. `.env.example` কপি করে `.env` নাম দিন।
4. `.env` ফাইলে অবশ্যই `ADMIN_PASSWORD` এবং `SESSION_SECRET` শক্তিশালী ও আলাদা মান দিয়ে পরিবর্তন করুন। উদাহরণ পাসওয়ার্ড ব্যবহার করবেন না।
5. `npm start` চালান।
6. ব্রাউজারে `http://localhost:3000` খুলুন।
7. অ্যাডমিন প্যানেল: `http://localhost:3000/admin.html`

## পেমেন্ট সম্পর্কে জরুরি কথা

- ক্যাশ অন ডেলিভারি অর্ডার নেওয়ার জন্য প্রস্তুত।
- বিকাশ/নগদ অপশনে ক্রেতা মার্চেন্ট নম্বরে টাকা পাঠিয়ে Transaction ID দিতে পারবেন। নম্বর `.env`-এ বসাতে হবে এবং অ্যাডমিনকে পেমেন্ট যাচাই করতে হবে।
- এটি এখনো bKash/Nagad-এর স্বয়ংক্রিয় পেমেন্ট গেটওয়ে নয়। অটো পেমেন্ট চালু করতে বৈধ merchant account, provider API credentials এবং server-side gateway integration প্রয়োজন। গোপন API key কখনো ব্রাউজারের কোডে দেবেন না।

## অনলাইনে প্রকাশের আগে

- HTTPS-সহ Node.js hosting ব্যবহার করুন।
- `.env`, `store.db` ও `public/uploads`-এর স্থায়ী নিরাপদ ব্যাকআপ রাখুন।
- `.env` বা database ফাইল public folder-এ রাখবেন না।
- admin password ও session secret পরিবর্তন করুন।
- ডেলিভারি চার্জ, রিটার্ন নীতি, যোগাযোগ নম্বর ও merchant নম্বর যোগ করুন।
- লাইভে ব্যবহারের আগে test order দিয়ে পুরো প্রক্রিয়া যাচাই করুন।

## সীমাবদ্ধতা

এই প্যাকেজটি কাজ করার মতো বেসিক স্টোরফ্রন্ট ও অ্যাডমিন সিস্টেম দেয়, কিন্তু নিজে থেকে ইন্টারনেটে হোস্ট হয় না। নিরাপদ লাইভ চালাতে hosting, HTTPS, environment setup এবং payment merchant integration আলাদাভাবে সম্পন্ন করতে হবে। Session store SQLite-এ সংরক্ষিত হয়। নিয়মিত database backup রাখুন এবং hosting-এ স্থায়ী file storage নিশ্চিত করুন।
